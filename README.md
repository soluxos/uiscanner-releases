# UIScanner

Find UI inconsistencies on any page or a whole site – spacing, type, colour, radius and components – and check them against your design system.

**Download**

- Mac: [Apple silicon (M1 and later)](https://github.com/soluxos/uiscanner-releases/releases/latest/download/UIScanner-arm64.dmg) · [Intel](https://github.com/soluxos/uiscanner-releases/releases/latest/download/UIScanner-x64.dmg)
- Windows 10 and 11 (64-bit): [UIScanner-Setup.exe](https://github.com/soluxos/uiscanner-releases/releases/latest/download/UIScanner-Setup.exe)

Installed copies update themselves: when a new version is out, UIScanner shows **Update available** in its sidebar.

> These builds aren't signed yet. On a Mac, the first time you open UIScanner, right-click it in Applications and choose **Open**. On Windows, if SmartScreen says it protected your PC, choose **More info → Run anyway**.

This repository holds release downloads only. What's new in each version is on the [releases page](https://github.com/soluxos/uiscanner-releases/releases).
