# UIScanner

Find UI inconsistencies on any page or a whole site – spacing, type, colour, radius and components – and check them against your design system.

**Download for Mac**

- [Apple silicon (M1 and later)](https://github.com/soluxos/uiscanner-releases/releases/latest/download/UIScanner-arm64.dmg)
- [Intel](https://github.com/soluxos/uiscanner-releases/releases/latest/download/UIScanner-x64.dmg)

Installed copies update themselves: when a new version is out, UIScanner shows **Update available** in its sidebar.

> These builds aren't notarised by Apple yet. The first time you open UIScanner, right-click it in Applications and choose **Open**.

This repository holds release downloads only. What's new in each version is on the [releases page](https://github.com/soluxos/uiscanner-releases/releases).
